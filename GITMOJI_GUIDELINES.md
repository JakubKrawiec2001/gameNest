# Gitmoji Commit Message Guide

Prefix every commit message with a single **Gitmoji** emoji to convey the purpose of the change at a glance.

```text
<emoji> <imperative‑mood summary>
```

**Rules**

- Keep the summary up to 50 characters.
- Wrap any body text at 72 characters.
- Use the imperative mood (e.g., **Add**, **Fix**, **Refactor**).
